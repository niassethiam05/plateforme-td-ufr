# Frontend — Plateforme de fiches de TD (UFR)

Application React + TypeScript + Vite + Tailwind CSS.

Voir le README à la racine du monorepo pour les instructions de démarrage
complètes (backend, base de données, stockage de fichiers).

```bash
npm run dev      # serveur de développement (http://localhost:5173)
npm run build    # build de production
npm run lint     # lint (oxlint)
```
